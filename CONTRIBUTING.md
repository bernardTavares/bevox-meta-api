# Contributing

Thanks for looking. This repo is a reference implementation from the [4-layer AI-first company series](https://github.com/bernardTavares), so the bar is "makes it clearer or more correct", not "adds features".

- **Questions or ideas:** open a thread in [Discussions](../../discussions).
- **Bugs:** open an issue with steps to reproduce, the expected result and the actual result.
- **Pull requests:** keep them small and focused. Run `pnpm lint && pnpm typecheck && pnpm test` before opening one, and add a test for any behaviour change.
- **Security:** don't open a public issue; use GitHub's private vulnerability reporting on this repo.
